# Expenses — دفتر حساب کلبه

داشبورد هزینه‌های کلبه (بابل‌کنار) با ویرایش دائمی. داده‌ها در فایل
`data/expenses.json` نگهداری می‌شوند، در گیت نسخه‌بندی می‌شوند و هر ویرایش
در داشبورد مستقیم روی همین فایل ذخیره می‌شود (کاملاً آفلاین و خصوصی).

## نسخه آنلاین (GitHub Pages)

بعد از فعال‌کردن Pages، داشبورد اینجا باز می‌شود:

**https://17mohammad1718-png.github.io/Expenses/**

روی نسخهٔ آنلاین سرور Node وجود ندارد؛ داده از `data/expenses.json` خوانده
می‌شود و ویرایش‌ها در **همین مرورگر** (`localStorage`) می‌مانند. برای ذخیرهٔ
دائمی روی دیسک همان اجرای محلی را استفاده کنید.

### یک‌بار فعال‌سازی Pages

1. در مخزن برو به **Settings → Pages**
2. در **Source** گزینهٔ **GitHub Actions** را انتخاب کن
3. بعد از merge شدن این تغییرات به `main`، اکشن `Deploy GitHub Pages` سایت را منتشر می‌کند

روش جایگزین (بدون Actions): Source را روی **Deploy from a branch** بگذار،
شاخه `main` و پوشه `/ (root)` را انتخاب کن.

> مخزن الان **عمومی** است؛ هر کسی می‌تواند مبالغ و شرح تراکنش‌ها را ببیند.
> اگر دفتر حساب باید خصوصی بماند، مخزن را Private کنید یا Pages را روشن نکنید.

## اجرا

```bash
node server.js
```

سپس در مرورگر: **http://localhost:3000**

نیازی به نصب هیچ بسته‌ای نیست — سرور فقط با ماژول‌های داخلی Node کار می‌کند.

- تفکیک مخارج بر اساس دفتر (کارت ملت / سرویس آب / تبلیغات) و دسته

  ردیف‌های مشترک (هر دو نفر) **نصف نصف** بین دو نفر تقسیم می‌شوند
- افزودن / ویرایش / حذف ردیف با ذخیرهٔ دائمی روی دیسک
- بکاپ خودکار قبل از هر ذخیره در `data/backups/`
- نمودار روند ماهانه و تفکیک دسته‌ها
- جستجو، فیلتر و مرتب‌سازی جدول

## ساختار داده

هر ردیف یک تراکنش است:

```json
{
  "id": 1,
  "desc": "محمد",
  "date": "1405/02/17",
  "amount": 2000000,
  "category": "personal",
  "source": "card",
  "who": "m"
}
```

- `source`: دفتر ثبت — `card` کارت ملت / `water` سرویس آب / `ads` تبلیغات
- `category`: دسته هزینه — `personal`, `settlement`, `water`, `materials`,
  `hospitality`, `ads`, `tax`, `misc`
- `who` فقط برای `personal`: `m` محمد / `z` زهرا / `both` هر دو (نصف نصف)

## به‌روزرسانی از اکسل

وقتی ردیف جدیدی به اکسل اضافه شد:

```bash
python scripts/excel_to_json.py <file.xlsx>
python scripts/validate.py
```

اسکریپت تبدیل، سه جدول داخل شیت (کارت ملت، سرویس آب، تبلیغات) را می‌خواند
و دسته‌بندی را با کلمات کلیدی انجام می‌دهد؛ استثناها در `EXACT_OVERRIDES`
قابل تنظیم‌اند.

## API

| GET | `/api/expenses` | خروجی کامل JSON |
| POST | `/api/expenses` | ذخیرهٔ کامل مجموعه (بدنه = آرایه) |
